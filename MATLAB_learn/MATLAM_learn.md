## fprintf（）

### 基本语法：

* 命令行输出：`fprintf(formatSpec, A1, A2, ...)`
* 文件输出：`fprintf(fileID, formatSpec, A1, ...)`

### 占位符

| **转换字符** | **说明**                           |
| ------------ | ---------------------------------- |
| `%d`         | 有符号整数                         |
| `%f`         | 固定小数点引浮点数                 |
| `%e`         | 科学计数法（小写 e）               |
| `%g`         | 自动选择 `%f` 或 `%e` 中较短的一个 |
| `%s`         | 字符串或字符向量                   |
| `%%`         | 输出一个百分号字符                 |

| **标志**       | **功能描述**                                             | **示例代码**          | **输出结果 (假设宽度为6)** |
| -------------- | -------------------------------------------------------- | --------------------- | -------------------------- |
| **`-` (负号)** | 左对齐。在指定的宽度内向左靠拢（默认是右对齐）。         | `fprintf('%-6d', 42)` | `'42    '`                 |
| **`+` (加号)** | 始终显示符号。正数显示 `+`，负数显示 `-`。               | `fprintf('%+6d', 42)` | `'   +42'`                 |
| **`0` (零)**   | 补零。在宽度范围内，用`0`替代空格填充前导位置。          | `fprintf('%06d', 42)` | `'000042'`                 |
| **` ` (空格)** | 保留正号位。正数前加空格，负数前加 `-`，使正负数对齐。   | `fprintf('% 6d', 42)` | `'    42'`                 |
| `#` (**井号**) | 修改转换方式。常用于十六进制或八进制，保留前缀或小数点。 | `fprintf('%#x', 42)`  | `'0x2a'`                   |

> 可以在`%`和转换字符之间加入数字来控制显示样式： `%[标志][宽度][.精度]转换字符`
>
> * 宽度 (Width)： 输出的总字符数（包括小数点）。如果实际长度小于宽度，默认补空格。
>
> * 精度 (Precision)：
>   * 对于`%f`，表示小数点后的位数。
>   * 对于`%g`，表示有效数字的总位数。



## 分支结构

### 单分支结构

```matlab
if expression
    % 执行代码块
end
```

### 双分支结构

```matlab
if expression
    % 条件为真执行
else
    % 条件为假执行
end
```

### 多分支结构

```matlab
if expression1
    % 代码块1
elseif expression2
    % 代码块2
else
    % 以上都不满足执行
end
```

```matlab
switch switch_expression
    case case_expression1
        % 代码块1
    case {case_expression2, case_expression3} % 可以使用元胞数组匹配多个值
        % 代码块2
    otherwise
        % 相当于 else
end
```

## 循环结构

### for 循环

```matlab
for index = values
    % 执行代码
end
```

### while 循环

```matlab
while expression
    % 执行代码块
end
```
